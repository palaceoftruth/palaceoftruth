{{- else }}

WARNING: Postgres backups are OFF.
  This release runs a database with no scheduled backup and no WAL archive,
  so a lost volume is lost data. Backups need an object-store destination and
  credentials that belong to this environment, which is why the chart cannot
  turn them on for you.

  To enable:
    postgres.backup.enabled: true
    postgres.backup.objectStore.configuration.destinationPath: s3://BUCKET/PATH
    plus the provider credential references (or workload identity)

  The Barman Cloud plugin and its CRDs must be installed in the cluster first.
  Set postgres.backup.requireBackup=true in production values so this can
  never ship unnoticed again.
{{- end }}
