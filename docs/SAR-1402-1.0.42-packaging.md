# 1.0.42 source packaging — published asset completeness repair

Source-only manifest version is now **1.0.42**. No tag, GitHub release, registry
publication, deployment or profile installation is performed by this document.

## Why 1.0.42 exists

The published `palaceoftruth-hermes-memory-plugin-v1.0.41` asset was **incomplete**:
its tar.gz/zip carried only four members
(`plugin/__init__.py`, `plugin/plugin.yaml`, `README.md`, `Dockerfile`) and
omitted `checkpoint.py`, `outbox.py`, `credentials.py`, `cli.py`. The package
could not be imported (`ModuleNotFoundError: No module named 'plugin.checkpoint'`).
That asset is **UNUSABLE** as a plugin release.

Root cause: `scripts/package_hermes_memory_plugin.py` held a 4-entry
`PLUGIN_FILES` allowlist, while the reviewed recovery packager ships all eight
plugin files.

## Repair

- `PLUGIN_FILES` now lists all eight shipped files, membership-equal to
  `scripts/package_hermes_recovery.py`.
- Archives are deterministic: fixed tar member mode/uid/gid/mtime, gzip
  `mtime=SOURCE_DATE_EPOCH`, zip fixed DOS timestamp. Two builds with the same
  `SOURCE_DATE_EPOCH` are byte-identical.
- The 1.0.41 release asset is not deleted or mutated. The publish workflow
  refuses to reuse an existing tag and requires a version bump, so the fix is a
  new immutable patch version, 1.0.42.
- Regression coverage: `backend/tests/test_plugin_release_packaging.py` runs the
  real packaging script and asserts membership completeness, source byte
  equality, inventory integrity, byte determinism, absence of raw secret
  receipts, and a real package import of all modules.

## Build

    SOURCE_DATE_EPOCH=<epoch> python scripts/package_hermes_memory_plugin.py --output-dir <scratch>

Recovery packaging (`scripts/package_hermes_recovery.py`) is unchanged and its
required gate (81 recovery + 13 artifact CLI + 30 tenant per pinned host) still
applies; its artifact digest changes only because `plugin.yaml` now carries the
new version.

No merge, publish, install, live canary, production write or Done is claimed here.
